# Nassau Candy – Factory Reallocation & Shipping Optimization

## Project Overview

The **Nassau Candy Factory Reallocation and Shipping Optimization Recommendation System** is a data analytics project developed using Microsoft Power BI.

The project focuses on analyzing factory performance, product sales, profitability, and shipping performance to support better business decisions.

It helps identify factory-wise performance, understand shipping patterns, and explore opportunities for improving factory allocation and shipping efficiency.

## Project Objectives

- Analyze sales and profit across different factories.
- Evaluate product-wise sales performance.
- Compare factory contributions.
- Analyze shipping performance across different shipping modes.
- Study regional sales distribution.
- Support data-driven factory allocation and shipping decisions.

## Tools & Technologies

- **Microsoft Power BI Desktop** – Dashboard development and visualization.
- **Power Query** – Data cleaning and transformation.
- **CSV / Excel** – Dataset management.
- **DAX** – Calculated measures and analytics.

## Dataset Description

The project uses the Nassau Candy Distributor dataset.

The dataset contains information about:

- Order ID and Order Date
- Ship Date and Ship Mode
- Customer and Location details
- Product Name and Product ID
- Sales and Units
- Gross Profit and Cost
- Shipping Lead Time
- Current Factory

The dataset contains 10,194 records.

## Dashboard Pages

### Page 1 – Executive Overview

Provides a summary of overall business performance.

Includes:
- Total Units
- Total Gross Profit
- Total Orders
- Total Sales
- Sales Contribution by Factory
- Product-wise Sales Performance
- Sales Performance by Shipping Mode

### Page 2 – Factory & Product Analysis

Focuses on factory performance and product-level analysis.

Includes:
- Factory-wise unit sales
- Gross profit contribution
- Product-wise sales performance
- Regional sales analysis
- Sales and gross profit comparison

### Page 3 – Shipping & Logistics Analysis

Focuses on shipping efficiency and factory comparisons.

Includes:
- Factory filters
- Product filters
- Shipping performance analysis
- Factory comparison
- Shipping and optimization insights
